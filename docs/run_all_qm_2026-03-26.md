## QM Orchestration Script (Ni-center + Ligands)

This review document covers `scripts/run_all_qm.sh`.

### What it runs
- Ni-center ORCA workflow **sequentially** in one background track:
  1. `small_opt` (optimization)
  2. `small_freq` (frequency / Hessian)
  3. `large_mk` (RESP/CHELPG ESP)
- Ligand ORCA workflow **in parallel batch** in a second background track:
  - capped at 6 concurrent ligand jobs (`ORCA_OPT_MAX_JOBS=6`)

Both tracks run concurrently and the script waits for both to finish.

### Core budgeting (requested)
- Ni-center track: `nprocs=12` and `%maxcore=4000` per ORCA run
- Ligands track: 6 jobs * 6 cores/job = 36 cores
- Total: 48 cores, leaving headroom on the 56-core machine

### Logging
The script creates a timestamped folder under:
- `logs/qm_run_all_<timestamp>/`

It writes:
- `master.log` (master output)
- `ni_center_track.log` (Ni-center track)
- `ligands_orca_track.log` (ligands track)

Per-job ORCA logs remain in their respective directories.

### Notes on ωB97X-D4 inputs
The Ni-center track temporarily overwrites `small_opt.inp`, `small_freq.inp`, and `large_mk.inp` with their corresponding `_wB97XD4` method variants **so ORCA keeps the expected base file names** (e.g., `small_opt.gbw`). The script restores the original inputs on exit.
