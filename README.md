# Urease MD

An AMBER molecular dynamics and metal center parameterization pipeline for *Helicobacter pylori* urease in complex with quinazolinone derived inhibitors.

The active site of urease holds two Ni(II) ions bridged by a carbamylated lysine and a hydroxide. Standard force fields do not describe this site, so this repository builds a bonded model for the dinuclear nickel center from quantum chemistry, parameterizes a library of inhibitors, and runs equilibration and production MD for each protein inhibitor complex.

This work was carried out as an undergraduate research project at the College of Chemical Sciences, Institute of Chemistry Ceylon, Sri Lanka, supervised by Dr. Anton S. Perera. Part of it was presented as an oral talk at ACS Fall 2026.

## What is in the pipeline

| Phase | What it does | Main tools |
|---|---|---|
| 1. Structure preparation | Cleans PDB 6ZJA, assigns protonation states, builds the UreA and UreB monomer model | pdb4amber, custom Python |
| 2. Ni(II) parameterization | Cuts a QM cluster around the dinuclear Ni site, runs DFT (including broken symmetry calculations for the coupled Ni(II) pair), derives bonded terms by the Seminario method and charges by multi frame RESP | ORCA, MCPB.py, GFN2-xTB, Multiwfn |
| 3. Inhibitor parameterization | Builds GAFF2 parameters and RESP charges for each ligand | antechamber, parmchk2, ORCA |
| 4. System assembly | Solvates and neutralizes each complex, checks box clearance | tleap |
| 5. Equilibration | Staged minimization, heating and density equilibration with automatic convergence gates | pmemd.cuda |
| 6. Production MD | Restartable production runs with a resilient job queue | pmemd.cuda |
| 7. Analysis | Trajectory processing and MM/PBSA binding estimates | cpptraj, MMPBSA.py |

## Getting started

1. Install AmberTools and AMBER (pmemd.cuda), ORCA 6, and Multiwfn.
2. Edit `config.env` so the software paths point to your own installation. The paths in this repository are the ones used on the lab workstation.
3. Run `bash scripts/check_dependencies.sh` to confirm everything is found.
4. Follow `00_MASTER_GUIDE.md` phase by phase. Every step lists the command to run, a check to confirm it worked, and why it is done.

## Notes

- Large simulation outputs (trajectories, restart files, topologies) are not stored in this repository. They are regenerated by the scripts.
- `08_troubleshooting.md` and `docs/` record real problems that came up during the project, such as atom ordering in tleap, Ni geometry drift during equilibration and ORCA parser limits. They may save you time if you are setting up a similar metalloenzyme system.
